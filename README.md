# Therapy Skill Kit

A static educational website for practical CBT, DBT, mindfulness, wellness, goal-setting, emotional-regulation, interpersonal-effectiveness, and recreativity skills.

## Site structure

- `index.html`: editorial landing page
- `learn/index.html`: learning library with eight skill areas
- `skills-finder/index.html`: browser-only skill matching app
- `styles.css`: responsive site styles
- `app.js`: navigation and Skills Finder behavior
- `.github/workflows/pages.yml`: GitHub Pages deployment

## Skills Finder privacy

The Skills Finder runs entirely in the visitor's browser. It does not send or store the text entered into the form.

## Important

The site is educational and is not a substitute for professional mental health care, diagnosis, or emergency services.
